Business/Location Information

Fire Extinguisher Management & Compliance (BS 5306)

BS 5306-3:2009 Compliance Requirements

  • Monthly Visual Inspections: Check pressure, condition, accessibility
  • Annual Service: By competent person with detailed inspection
  • 5-Year Extended Service: Internal examination and pressure test
  • 10-Year Replacement: Complete replacement or major overhaul
  • Documentation: All inspections and services must be recorded

Fire Safety Compliance Assessment

Are adequate fire detection systems installed and maintained?

Fire Detection Improvements Required

Install smoke detectors in all rooms and corridors
Test all existing smoke alarms and replace batteries
Install interconnected alarm system throughout property
Are fire escape routes clearly marked and unobstructed?

Fire Escape Improvements Required

Clear all escape routes of obstructions immediately
Install or improve emergency exit signage throughout property
Install emergency lighting on escape routes
Are appropriate fire extinguishers installed and regularly maintained?

Fire Extinguisher Improvements Required

Install appropriate type and number of fire extinguishers
Schedule annual service for all fire extinguishers
Create monthly inspection schedule and documentation
Is electrical installation safe and compliant with current standards?

Electrical Safety Improvements Required

Obtain current electrical installation certificate (EICR)
Replace any faulty or damaged electrical equipment
Install RCD protection for all circuits
